## 中文

一间可以走进去逛的 3D 雪夜小屋，也是我的交互式个人简历网站，用于求职展示。

### 关于

打开网站先来到一间雪夜木屋：窗外飘雪、台灯暖光、唱片机在转。屋里的物品各对应简历的一部分——桌上的红色手账本翻开就是完整简历，电脑是作品集，墙上挂着奖状和照片，报纸是学院的公众号报道。全站支持中英文切换。

### 功能

- 🏠 Three.js 3D 小屋：可拖动转视角，点击发光的物品查看内容，点任意角落「走近看看」
- 📓 手账本简历：翻页式导航，支持标签、滑动、方向键切换，字号可调
- 🏆 奖状墙 / 🖼️ 照片墙：翻转卡片、点击放大，可左右翻看
- 🎵 唱片机：点击播放雪夜钢琴，黑胶随音乐转动
- 🐈 地毯上睡着一只小橘猫，点它会「喵」一声
- 🌐 中英文一键切换 · 📱 桌面端与移动端自适应

### 技术栈

纯 HTML / CSS / JavaScript + Three.js（无构建工具），部署于 GitHub Pages。

封面 · 教育背景 · 竞赛经历 · 实习经历 · 校园经历 · 爱好 · 作品集 · 技能与联系

## English

A 3D snowy cabin you can walk around in — and my interactive personal resume website, built for job hunting.

### About

The site opens in a snowy-night log cabin: snow outside the window, a warm desk lamp, a turning record player. Each object in the room holds part of my resume — the red notebook on the desk opens the full resume, the laptop shows my portfolio, the walls hold my certificates and photos, and the newspaper links to the faculty's news feature. Fully bilingual.

### Features

- 🏠 Three.js 3D cabin: drag to look around, click glowing objects, or click any corner to walk closer
- 📓 Notebook resume: page navigation by tabs, swipe or arrow keys, adjustable text size
- 🏆 Award wall / 🖼️ Photo wall: flip cards and click-to-zoom galleries
- 🎵 Record player: plays snowy-night piano while the vinyl spins
- 🐈 A little orange cat sleeps on the rug — click it for a meow
- 🌐 One-click Chinese/English toggle · 📱 Responsive on desktop and mobile

### Tech Stack

Plain HTML / CSS / JavaScript + Three.js (no build step), deployed on GitHub Pages.
