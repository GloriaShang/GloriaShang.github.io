## 中文

一个手账本风格的交互式个人简历网站，用于求职展示。

### 关于

这个网站以"手账本"为视觉概念，收录了教育背景、竞赛获奖、实习经历、校园活动等内容，支持中英文切换。

### 功能

- 📖 手账本翻页式导航，支持点击标签、滑动、方向键切换
- 🌐 中英文一键切换
- 🖼️ 证书与照片点击放大查看，支持滚轮缩放
- 📱 桌面端与移动端自适应

### 技术栈

纯 HTML / CSS / JavaScript（无框架依赖），单文件自包含，部署于 GitHub Pages。

### 内容板块

封面 · 教育背景 · 竞赛经历 · 实习经历 · 校园经历 · 爱好 · 联系方式
